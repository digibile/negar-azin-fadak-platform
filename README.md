# پلتفرم بیزینس نگار آذین فدک ایران

سامانه یکپارچه مدیریت کسب‌وکار نگار آذین فدک.

## ساختار اصلی
- `apps/web`: رابط وب و مرکز مدیریت
- `apps/api`: سرویس‌ها و منطق دامنه
- `packages/ui`: اجزای رابط مشترک
- `packages/shared`: مدل‌ها و قراردادهای مشترک
- `packages/config`: تنظیمات مشترک
- `database/migrations`: مهاجرت‌های نسخه‌گذاری‌شده پایگاه داده
- `docs/architecture/BOOK-2026.md`: کتاب مرجع واحد معماری، طراحی، کیفیت و انتشار

## مرکز مدیریت
مرکز مدیریت نگار آذین فدک از منوی مرکزی سازمان و ۲۰ پنل canonical استفاده می‌کند. کدهای منوی قدیمی از طریق نگاشت واحد به قابلیت‌های جدید هدایت می‌شوند و برای قابلیت مشترک، پنل موازی ساخته نمی‌شود.

## چرخه توسعه و انتشار
توسعه و بررسی در مخزن اصلی انجام می‌شود. Push فقط Build و تست و artifact قابل بازبینی تولید می‌کند. استقرار روی سرور فقط پس از تأیید صریح SHA دقیق انجام می‌شود.

برای قواعد معماری و معیار پایان هر قابلیت، فقط [کتاب مرجع پروژه ۲۰۲۶](docs/architecture/BOOK-2026.md) را دنبال کنید.

## قالب‌های خودرویی سوکار

قالب‌های واکنش‌گرای فارسی بازار خودرو در مسیرهای زیر قرار دارند:

- `/store/auto` بازار خودرو و جست‌وجوی اولیه
- `/store/auto/installments` مسیر خرید اقساطی
- `/store/auto/trade-in` تعویض و معاوضه خودرو
- `/store/auto/efi` خدمات فنی و EFI

این صفحات قالب رابط کاربری هستند؛ قیمت، مشخصات خودرو، شرایط اعتبار، ارزش کارشناسی و رزرو خدمات باید به سرویس‌های عملیاتی تأییدشده متصل شوند و به‌صورت ساختگی نمایش داده نمی‌شوند.
