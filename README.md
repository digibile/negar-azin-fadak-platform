# پلتفرم بیزینس نگار آذین فدک ایران

سامانه یکپارچه مدیریت کسب‌وکار نگار آذین فدک

## ساختار اصلی

- `apps/web` رابط کاربری
- `apps/api` سرویس‌های اصلی سامانه
- `packages/ui` اجزای رابط کاربری مشترک
- `packages/shared` مدل‌ها و قراردادهای مشترک
- `packages/config` تنظیمات مشترک
- `database/migrations` مهاجرت‌های پایگاه داده
- `docs` مستندات فنی و معماری

## مرکز مدیریت

### منوی مرکزی سازمان

- سازمان و ساختار
- مالی و حسابداری
- اعتبار
- تجارت
- مدیریت کاربران و دسترسی
- مدیریت قالب
- مدیریت منو
- مدیریت Frontend

## اصل توسعه

تمام توسعه، تست و تکمیل پروژه در GitHub و Codespaces انجام می‌شود.

استقرار روی سرور اصلی فقط پس از تکمیل و تأیید نسخه نهایی انجام خواهد شد.
