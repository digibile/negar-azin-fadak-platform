# ابزارهای مشترک محیط‌های مدیریتی

این پوشه ابزارهای قابل استفاده مجدد رابط مدیریت را نگهداری می‌کند.

## ManagementToolbar
نوار عملیات صفحه برای ایجاد، ورود CSV با پیش‌نمایش و تأیید، خروجی CSV، چاپ و ارسال. عملیات ورود فقط زمانی نمایش داده می‌شود که صفحه یک تابع ثبت واقعی از طریق `onImport` ارائه کند. خروجی از داده‌های واقعی همان صفحه ساخته می‌شود.

## ManagementDialog
پنجره استاندارد با حالت عادی و تمام‌صفحه، بستن با Escape، بستن با کلیک بیرون، و هشدار تغییرات ذخیره‌نشده. فرم‌ها باید `dirty` را به وضعیت واقعی تغییرات متصل کنند.

## قواعد
- ابزار پایه به API، نقش یا منطق دامنه وابسته نیست.
- پنجره فوکوس را هنگام بازشدن دریافت می‌کند، با کلید Tab داخل پنجره نگه می‌دارد و پس از بسته‌شدن فوکوس را به عنصر قبلی برمی‌گرداند.
- صفحه مصرف‌کننده باید عملیات را با مجوز و endpoint واقعی کنترل کند.
- ورود فایل فقط پس از اعتبارسنجی و تأیید کاربر به callback صفحه تحویل داده می‌شود.
- CSV ابزار عمومی فعلی است؛ خروجی PDF/Excel باید با سرویس/کتابخانه معتبر پروژه و نیاز واقعی صفحه اضافه شود، نه با تغییر پسوند فایل.


## کنترل ساختار CSV
- parser فقط کوتیشن ابتدای مقدار را می‌پذیرد؛ کوتیشن بدون جفت یا نویسه غیرمجاز پس از کوتیشن بسته‌شده رد می‌شود.
- کوتیشن دوتایی داخل مقدار نقل‌قول‌شده به‌صورت escape خوانده می‌شود و خط جدید داخل مقدار نقل‌قول‌شده حفظ می‌شود.
- عنوان ستون‌ها پس از trim و بدون حساسیت به بزرگی/کوچکی حروف لاتین باید یکتا باشند.
- فایل نامعتبر قبل از ساخت پیش‌نمایش و پیش از فراخوانی callback ثبت رد می‌شود.


## پنجره‌های تو‌در‌تو
- پنجره‌ها در یک پشته مشترک ثبت می‌شوند؛ فقط پنجره بالایی کلید Escape و Tab را مدیریت می‌کند.
- بستن پنجره بالایی، پنجره زیرین را فعال نگه می‌دارد و مدیریت فوکوس آن به‌صورت طبیعی ادامه پیدا می‌کند.
- وضعیت تغییرات ذخیره‌نشده از طریق ref خوانده می‌شود تا listener صفحه‌کلید با هر تغییر فرم دوباره نصب نشود و فوکوس بی‌دلیل جابه‌جا نشود.
