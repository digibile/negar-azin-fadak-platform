# نقشه ماژول‌های سامانه یکپارچه مدیریت کسب‌وکار نگار آذین فدک

این سند قرارداد اجرایی ساخت پروژه است. درخت محصول ۴۵ حوزه دارد، اما پیاده‌سازی در هشت هسته انجام می‌شود تا هر تغییر کوچک مجبور نباشد کل سامانه را دوباره بسازد.

## هسته‌ها

1. core: حوزه‌های 01 تا 07
2. finance: حوزه‌های 08 تا 10
3. credit: حوزه‌های 11 تا 15
4. commerce: حوزه‌های 16 تا 22
5. communication: حوزه‌های 23 تا 27
6. documents-content: حوزه‌های 28 تا 34
7. organization: حوزه‌های 35 تا 37
8. command-platform: حوزه‌های 38 تا 45

## قوانین ساخت

- هر قابلیت باید API، migration، permission، test و UI واقعی داشته باشد.
- داده تجاری ساختگی وارد مسیر تولید نمی‌شود.
- PostgreSQL پایگاه داده اصلی است.
- احراز هویت و دسترسی واقعی هستند.
- نام‌گذاری محصول از واژگان رسمی نگار آذین فدک استفاده می‌کند.
- هیچ secret یا credential در repository قرار نمی‌گیرد.
- هر مرحله باید با GitHub Actions قابل Build و Test باشد.
