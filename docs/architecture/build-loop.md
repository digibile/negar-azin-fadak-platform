# چرخه ساخت خودکار

مرجع اصلی کد GitHub است. توسعه به تغییرات کوچک و قابل Build تقسیم می‌شود.

```
Task
  -> implementation
  -> migration/API/UI/tests
  -> commit
  -> GitHub Actions
  -> build + test
  -> merge/release
```

## ترتیب اجرا

1. زیرساخت و قراردادهای Core
2. هویت، کاربران و امنیت
3. داده‌های پایه و مشتری 360
4. مالی و خزانه
5. اعتبار، وام، اقساط و وصول
6. تجارت، Marketplace، تحویل، کمیسیون، تسویه و پرداخت
7. ارتباطات، CRM، مرکز تماس و پشتیبانی
8. اسناد، سایت، صفحه‌ساز، فرم‌ساز، محتوا و هوش نگار
9. منابع انسانی، پروژه و گزارش
10. مرکز فرماندهی، مانیتورینگ، حسابرسی، API، زیرساخت، موبایل و کیفیت
