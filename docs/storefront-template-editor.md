# راهنمای قالب‌ساز فروشگاه

## مسیر مدیریت
در مرکز مدیریت نگار آذین فدک، ماژول «مدیریت قالب‌های صفحات» (ماژول ۳۶) را باز کنید.

## روند انتشار
1. یک قالب آماده را برای شروع انتخاب کنید یا قالب تازه بسازید.
2. کد، عنوان و کلید قالب را ثبت کنید.
3. رنگ اصلی، رنگ تأکیدی، پس‌زمینه و سطح کارت‌ها را تنظیم کنید.
4. تعداد ستون محصولات را بین ۲ تا ۶ انتخاب کنید؛ سبک کارت و نسبت تصویر را مشخص کنید.
5. ترتیب بخش‌های بنر، مزایا، دسته‌بندی و محصولات را تعیین کنید.
6. نمایش بنر و دسته‌بندی و حالت هدر/فوتر را تنظیم کنید.
7. قالب را ذخیره و از فهرست قالب‌ها منتشر کنید.

## اعمال در فروشگاه
فروشگاه تنظیمات قالب فعال را از `GET /api/public/storefront-theme` دریافت می‌کند. API فقط فیلدهای نمایشی مجاز را بازمی‌گرداند و مقادیر رنگ و گزینه‌های چیدمان را اعتبارسنجی می‌کند. محصولات، قیمت، تخفیف و موجودی از تنظیمات قالب ساخته نمی‌شوند؛ آن‌ها همچنان از کاتالوگ واقعی خوانده می‌شوند.

## ایمنی و انتشار
قالب منتشرشده فقط برای دامنه‌ای اعمال می‌شود که به‌عنوان دامنه تأییدشده به سازمان مربوط متصل باشد. برای دامنه ناشناس، API به‌جای انتخاب خودکار سازمان پیش‌فرض، بدون قالب منتشرشده پاسخ می‌دهد. گردش‌کار انتشار ابتدا یکپارچگی، ساخت API، مهاجرت پایگاه داده، آزمون‌ها و ساخت وب را اجرا می‌کند؛ استقرار روی سرور تنها پس از موفقیت این مراحل و بررسی پیش‌نیازهای مقصد انجام می‌شود.
