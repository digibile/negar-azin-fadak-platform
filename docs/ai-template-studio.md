# طراح هوشمند قالب‌های سوکار

## مقصد و مسیر

- بخش مدیریت: `/admin/templates`
- محیط طراحی هوشمند: `/admin/templates/ai-studio`
- نام قابلیت: طراح هوشمند قالب‌ها
- ذخیره‌سازی: ماژول مرکزی `36-page-templates` در جدول `module_records`
- نوع رکورد: `page-template`
- وضعیت اولیه: `پیش‌نویس هوش مصنوعی`

## پیکربندی سرویس مدل

متغیرهای زیر فقط در محیط سرویس API تنظیم می‌شوند:

- `AI_API_KEY`: کلید ارائه‌دهنده سازگار با API چت تکمیل‌گفتگو
- `AI_API_BASE_URL`: نشانی پایه API؛ پیش‌فرض `https://api.openai.com/v1`
- `AI_MODEL`: شناسه مدل؛ پیش‌فرض `gpt-4.1-mini`

کلید API نباید در متغیرهای عمومی فرانت‌اند یا فایل‌های ارسالی مرورگر قرار بگیرد. پس از تنظیم متغیرها، سرویس API باید مجدداً راه‌اندازی شود.

## جریان کار

1. مدیر نوع صفحه، فناوری، زبان رابط و شرح نیاز را انتخاب می‌کند.
2. API پس از احراز هویت و بررسی مجوز `templates:manage` درخواست را به ارائه‌دهنده مدل ارسال می‌کند.
3. مدل فقط یک مشخصات طراحی ساخت‌یافته JSON تولید می‌کند؛ کد اجرایی مدل مستقیماً اجرا نمی‌شود.
4. رابط کاربری پیش‌نمایش ساختاری از عنوان، رنگ‌ها، بخش‌ها و اجزای پیشنهادی می‌سازد.
5. با انتخاب «ذخیره در کتابخانه قالب‌ها»، پیش‌نویس در رکوردهای ماژول قالب‌ها و در محدوده مستأجر جاری ذخیره می‌شود.
6. ذخیره پیش‌نویس، قالب فعال فروشگاه را تغییر نمی‌دهد.

## API

- `POST /api/ai/template-design/generate`: تولید مشخصات طراحی با هوش مصنوعی
- `GET /api/ai/template-design`: فهرست پیش‌نویس‌های هوش مصنوعی مستأجر جاری
- `POST /api/ai/template-design/save`: ذخیره پیش‌نویس در کتابخانه قالب‌ها

تمام درخواست‌های تغییردهنده از محافظ CSRF عمومی سرویس API عبور می‌کنند.

## دامنه نسخه فعلی

این نسخه، جریان انتخاب نیاز، تولید مشخصات طراحی، پیش‌نمایش واکنش‌گرا و ذخیره پایدار پیش‌نویس را فراهم می‌کند. تولید و اجرای خودکار فایل‌های منبع Next.js/Python، نصب وابستگی‌ها، ساخت بسته قابل استقرار و انتشار روی دامنه، مرحله جداگانه چرخه ساخت و انتشار است و در این نسخه انجام نمی‌شود. انتشار خودکار یا اجرای کد تولیدشده مدل عمداً فعال نشده است.
