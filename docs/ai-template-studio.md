# طراح هوشمند قالب‌های سوکار

## مقصد و مسیر

- بخش مدیریت: `/admin/templates`
- محیط طراحی هوشمند: `/admin/templates/ai-studio`
- نام قابلیت: طراح هوشمند قالب‌ها
- ذخیره‌سازی: ماژول مرکزی `36-page-templates` در جدول `module_records`
- نوع رکورد: `page-template`
- وضعیت اولیه: `پیش‌نویس هوش مصنوعی`

## پیکربندی سرویس مدل

متغیرهای زیر فقط در محیط سرویس API تنظیم می‌شوند:

- `AI_API_KEY`: کلید ارائه‌دهنده سازگار با API چت تکمیل‌گفتگو
- `AI_API_BASE_URL`: نشانی پایه API؛ پیش‌فرض `https://api.openai.com/v1`
- `AI_MODEL`: شناسه مدل؛ پیش‌فرض `gpt-4.1-mini`

کلید API نباید در متغیرهای عمومی فرانت‌اند یا فایل‌های ارسالی مرورگر قرار بگیرد. پس از تنظیم متغیرها، سرویس API باید مجدداً راه‌اندازی شود.

## جریان کار

1. مدیر نوع صفحه، فناوری، زبان رابط و شرح نیاز را انتخاب می‌کند.
2. API پس از احراز هویت و بررسی مجوز `templates:manage` درخواست را به ارائه‌دهنده مدل ارسال می‌کند.
3. مدل فقط یک مشخصات طراحی ساخت‌یافته JSON تولید می‌کند؛ کد اجرایی مدل مستقیماً اجرا نمی‌شود.
4. رابط کاربری پیش‌نمایش ساختاری از عنوان، رنگ‌ها، بخش‌ها و اجزای پیشنهادی می‌سازد.
5. با انتخاب «ذخیره در کتابخانه قالب‌ها»، پیش‌نویس در رکوردهای ماژول قالب‌ها و در محدوده مستأجر جاری ذخیره می‌شود.
6. ذخیره پیش‌نویس، قالب فعال فروشگاه را تغییر نمی‌دهد.

## API

- `POST /api/ai/template-design/generate`: تولید مشخصات طراحی با هوش مصنوعی
- `GET /api/ai/template-design`: فهرست پیش‌نویس‌های هوش مصنوعی مستأجر جاری
- `POST /api/ai/template-design/save`: ذخیره پیش‌نویس در کتابخانه قالب‌ها

تمام درخواست‌های تغییردهنده از محافظ CSRF عمومی سرویس API عبور می‌کنند.

## دامنه نسخه فعلی

این نسخه، جریان انتخاب نیاز، تولید مشخصات طراحی، پیش‌نمایش واکنش‌گرا و ذخیره پایدار پیش‌نویس را فراهم می‌کند. تولید فایل‌های منبع Next.js/React/Python با مسیرهای محدود و نمایش کد برای بازبینی در این نسخه اضافه شده است. فایل‌ها فقط به‌عنوان پیش‌نویس در تعریف صفحه ذخیره می‌شوند؛ اجرای کد تولیدشده، نصب وابستگی‌ها، اعمال روی مسیرهای اصلی مخزن، ساخت بسته انتشار و انتشار روی دامنه نیازمند مرحله جداگانه بررسی و انتشار است و خودکار انجام نمی‌شود. انتشار خودکار یا اجرای کد تولیدشده مدل عمداً فعال نشده است.

## کارگاه هوشمند همه‌منظوره

مسیر رابط: `/admin/ai-workshop`

ابزارهای تخصصی:
- `page`: صفحه‌ساز
- `menu`: منوساز؛ ذخیره در `menu_items` با `is_active=false` تا منوی جاری تغییر نکند
- `layout`: چیدمان‌ساز
- `size`: سایزبندی و نقاط شکست
- `form`: فرم‌ساز؛ ذخیره در `form_definitions` با وضعیت `draft`
- `section`: بخش‌ساز
- `advertorial`: رپورتاژ و محتوای تبلیغاتی با افشای شفاف محتوای حمایت‌شده
- `report`: گزارش‌ساز؛ مشخصات شاخص و نمودار، بدون داده ساختگی
- `template`: قالب‌ساز

API:
- `POST /api/ai/workshop/generate`
- `POST /api/ai/workshop/save`

مجوز هر ابزار جداگانه کنترل می‌شود. خروجی‌های صفحه، چیدمان، سایزبندی، بخش، رپورتاژ، گزارش و قالب به‌صورت تعریف پیش‌نویس در `page_definitions` ذخیره می‌شوند. فرم‌ها در `form_definitions` ذخیره می‌شوند. منوهای تولیدشده به‌صورت غیرفعال در `menu_items` ذخیره می‌شوند و هیچ منوی فعالی را جایگزین نمی‌کنند.

دکمه «کارگاه هوشمند» در نوار بالای مرکز مدیریت قرار دارد و از ویرایشگرهای صفحه، فرم و منو نیز می‌توان مستقیماً ابزار مرتبط را باز کرد.

دامنه هدف استقرار: `sookar.ir`؛ CORS سرویس API برای ریشه و www این دامنه مجاز شده است.

### تولید کد منبع
- `POST /api/ai/workshop/code`: تولید فایل‌های منبع محدودشده بر اساس ابزار و فناوری انتخابی.
- فقط پسوندهای `.tsx`, `.ts`, `.css`, `.py` و مسیرهای پوشه تولیدشده مجاز هستند.
- فایل‌های محیط، کلیدها، مهاجرت SQL، اسکریپت shell، package manifest و deployment script پذیرفته نمی‌شوند.
- کد تولیدشده اجرا نمی‌شود؛ مدیر باید آن را بازبینی کند و سپس در چرخه ساخت کنترل‌شده قرار گیرد.
