# ورود دسته‌ای کاتالوگ واقعی دیجی‌بایل

این مسیر برای ورود کاتالوگ متعلق به فروشنده یا تأمین‌کنندهٔ مجاز به پایگاه دادهٔ داخلی است؛ از کاتالوگ مرجع دیجی‌کالا به‌عنوان موجودی قابل فروش استفاده نمی‌کند.

## API

`POST /api/marketplace/products/import-supplier-catalog`

- نیازمند نشست معتبر و مجوز `product:manage` است.
- هر درخواست حداکثر ۵۰۰ کالا می‌پذیرد؛ برای هزاران کالا باید دسته‌های چندمرحله‌ای ارسال شود.
- `sellerId` باید متعلق به مستأجر فعال کاربر باشد.
- `imageUrl` باید مسیر رسانهٔ داخلی پلتفرم با پیشوند `/api/public/media/catalog/` باشد. لینک تصویر خارجی به‌عنوان تصویر اصلی پذیرفته نمی‌شود.
- تمام کالاها ابتدا `draft` می‌مانند. ورود دسته‌ای به‌تنهایی موجودی، مالکیت کالا، قیمت یا مجوز فروش را تأیید نمی‌کند.
- پس از بررسی قیمت و اطلاعات کالا، موجودی واقعی باید از مسیر `PATCH /api/marketplace/products/:id/inventory` ثبت شود و سپس کالا از مسیر `PATCH /api/marketplace/products/:id/status` منتشر شود.
- شناسه‌های تکراری رد می‌شوند؛ قیمت فروش از منبع مرجع به‌صورت خودکار جایگزین نمی‌شود.

```json
{
  "sellerId": "UUID-OF-SELLER-IN-CURRENT-TENANT",

  "supplierReference": "شناسه قرارداد یا فایل کاتالوگ",
  "items": [
```

## محدودیت مهم

این endpoint مسیر فنی واردسازی را آماده می‌کند؛ خودش فهرست محصولات واقعی یا مجوز تأمین‌کننده تولید نمی‌کند. برای پرشدن کاتالوگ باید فایل یا API مجاز تأمین‌کننده، شناسهٔ فروشندهٔ فعال و فایل تصاویر واقعی در رسانهٔ داخلی در دسترس باشد. قیمت، موجودی و وضعیت انتشار هر کالا باید تأیید شوند.
